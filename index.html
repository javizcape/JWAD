Un despliegue, no una lista de tareas

WAD nació para técnicos, administradores de sistemas e integradores que necesitan dejar decenas de equipos listos para producción sin repetir la misma secuencia de clics una y otra vez. Todo el flujo corre en segundo plano: valida, instala, verifica y reporta.

01

Cero interacción

Todo el flujo corre desapercibido, sin ventanas de instalación que interrumpan al técnico.

02

Auto-elevación UAC

Detecta permisos insuficientes y se relanza como Administrador sin intervención manual.

03

Híbrido Winget + GitHub API

Usa el repositorio oficial de Microsoft y recurre a releases de GitHub cuando no hay paquete.

04

Telemetría real

CPU, RAM, disco y temperatura vía WMI/CIM entregados en un reporte JSON al finalizar.

Ejecución rápida

Abre PowerShell como Administrador, pega el comando y presiona Enter. WAD se encarga del resto.

Windows 10 / 11 (x64) 
irm https://javizcape.github.io/.ps1/install-apps.ps1 | iex
Alternativa si tu red o ISP bloquea el comando anterior 
iex (curl.exe -s https://javizcape.github.io/.ps1/install-apps.ps1 | Out-String)

Ejecuta PowerShell directamente como Administrador para evitar el paso extra de re-elevación.

Requisitos

  • Windows 10 u 11, arquitectura x64 (AMD64)
  • PowerShell 5.1 o superior
  • Conexión a internet activa
  • Winget instalado (incluido en builds modernas)

Características principales

Cada decisión del script está pensada para dejar un equipo auditable, no solo instalado.

Seguridad

Auto-elevación de privilegios (UAC)

Detecta si el usuario estándar requiere permisos de administrador y re-invoca la sesión sin interrumpir el flujo.

Compatibilidad

Filtro estricto de arquitectura

Validación en tiempo real que garantiza ejecución exclusiva en entornos de 64 bits (AMD64).

Instalación

Despliegue híbrido silencioso

Prioriza instalación nativa vía Winget; recurre a extracción por GitHub API para apps sin instalador oficial empaquetado (ej. FlyPhotos, AB Download Manager).

Confiabilidad

Gestión de errores integrada

Captura códigos de salida de Windows (0, 3010, etc.) para validar cada instalación antes de continuar.

Auditoría

Reporte de auditoría

Genera un JSON con hardware, rendimiento y estado final de cada aplicación instalada.

Cómo funciona

El mismo recorrido que hace el script, de principio a fin.

1

Verifica la arquitectura

Si el equipo no es AMD64, el script se detiene de inmediato.

2

Confirma privilegios de administrador

Si faltan, se re-invoca a sí mismo solicitando elevación UAC.

3

Recorre el catálogo de aplicaciones

Intenta primero la instalación nativa vía Winget.

4

Cae a GitHub API si no hay paquete

Descarga y extrae el release oficial cuando la app no está en Winget.

5

Valida el código de salida

Registra éxito o fallo por aplicación antes de continuar con la siguiente.

6

Ejecuta el diagnóstico de hardware

Consulta CPU, RAM, disco y temperatura vía WMI/CIM.

7

Genera Reporte_Despliegue.json

Guarda el resultado completo en el Escritorio, listo para auditoría.

Personalización

¿Necesitas otro catálogo para tus propios despliegues? Edita la sección de configuración del script y ajusta:

  • El listado de IDs de Winget a instalar
  • Las URLs de releases de GitHub para apps sin paquete oficial
  • El nombre y la ruta de salida del reporte JSON

Preguntas frecuentes

¿Por qué el comando falla en mi red corporativa?

Algunos proveedores o políticas de DNS bloquean irm. Usa el método alternativo con curl.exe de la sección de instalación.

¿Funciona en Windows con arquitectura ARM64?

No. WAD valida explícitamente AMD64 y detiene la ejecución en cualquier otra arquitectura.

¿Puedo ejecutarlo sin ser administrador?

Sí. El script detecta la falta de privilegios y se re-invoca a sí mismo solicitando elevación UAC.

Hoja de ruta
